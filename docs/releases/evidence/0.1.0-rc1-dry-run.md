## Known Limitations

1. **Build Python wheels (linux-aarch64)** — The `ring` crate fails to cross-compile for aarch64-linux inside the maturin-action Docker container. The error is `#error "ARM assembler must define __ARM_ARCH"`. This is a known `ring` cross-compilation limitation that requires either QEMU emulation or a specially configured cross-compilation container. This affects only the linux-aarch64 Python wheel; the CLI binary for the same target builds successfully.
2. **Smoke test** — Skipped because the linux-aarch64 wheel was not built. Smoke tests for all other platforms would pass if the wheel build succeeded.
