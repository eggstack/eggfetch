## 6. Candidate freeze

After all gates are green, record the exact commit SHA as
`0.2.1 release candidate`.

No further repository change may be folded into that candidate.

M002 must execute against this exact commit. M001B must later tag and publish
this exact commit.

Docs-only closure records may be descendants, but they do not replace the
candidate SHA.

## 7. Compatibility / Stage C disposition

A coordinated version bump alone is release identity, not a runtime semantic
change.

If the candidate audit proves no executable or qualification-input change
relative to the live freeze, Stage C remains
`5247ff0e01e309d9b408b8b4b4c90151ee5ce9fa`.

If that proof fails, do not claim the old Stage C binding covers the
candidate. Open/requalify first.
